# Руководство по внесению изменений 
## Формат коммитов (Conventional Commits)

Каждое сообщение должно строго следовать формату:
`<type>: <description>`

### Допустимые типы:
- `feat`: добавление новой функции (например, операции калькулятора).
- `fix`: исправление ошибки.
- `docs`: изменения в документации (README, CHANGELOG и т.д.).
- `style`: правки стиля кода (пробелы, форматирование) без изменения логики.
- `test`: добавление или изменение тестов.
